# M1 interface direction

Reading this as a compact lab workbench for five student contributors, with an evidence-first dark-teal visual language. ENERGY 1 / RHYTHM 2 / MOTION 1.

Direction comes from the accepted five-member plan: a compact workspace, readable sans-serif, monospace technical values, no marketing sections and no invented results.

- Dark navy surfaces keep the surrounding control workspace distinct from the target application during demonstrations.
- Teal marks the primary action and keyboard focus, not a claim that a test succeeded.
- System sans-serif keeps the lab offline and portable; monospace is reserved for versions, paths and content markers.
- The target strip precedes the application because configuration must be visible before a student interprets a response.
- A wide application view and a shorter handoff section reflect different content needs, not a card-grid template.
- On phones metadata stacks and the application gets the full available width. Controls have at least 44px touch areas.
- No logos, avatars, decorative icons, external fonts, charts or animation. Text status changes describe actual loading and failures.
- Fictional records are explicitly labelled synthetic. No experiment metrics appear in this M1 shell.
